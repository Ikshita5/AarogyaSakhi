# AarogyaSakhi 💗
### Your Companion for Women's Health

AarogyaSakhi is a women's health awareness platform designed to make symptom tracking, health insights and reliable health education more accessible.

## ✨ Features
- 📝 **Symptom Diary** — Track symptoms over time.
- 📊 **Pattern Insights** — Explore symptom trends and reports.
- 🧪 **Lab Result Education** — Understand laboratory results in simpler language.
- 🌸 **Health Resources** — Access women's health information.
- 💗 **Health Awareness** — Learn about PCOS, endometriosis, and anemia.
- 🩺 **Health Check-in Guide** — Explore health concerns and possible next steps.

## 🛠️ Tech Stack
- Python
- Streamlit

## 🚀 Run Locally

```bash
git clone https://github.com/Ikshita5/AarogyaSakhi.git
cd AarogyaSakhi
pip install -r requirements.txt
streamlit run app.py
```
